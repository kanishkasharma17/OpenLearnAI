# OpenLearn AI

## Problem

Independent educators need a platform to manage courses, assignments, quizzes and student progress without relying on large edtech companies.

## Goal

Build an open-source AI-powered learning management system.

## Users

### Teacher

- Create courses
- Upload lectures
- Upload notes
- Create quizzes
- Create assignments
- View analytics

### Student

- Enroll in courses
- Watch lectures
- Submit assignments
- Attempt quizzes
- Track progress

## ML Features

- Student Risk Prediction
- Personalized Recommendations
